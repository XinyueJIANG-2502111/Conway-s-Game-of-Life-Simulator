# コンウェイのライフゲームシミュレーター（OpenGL・C++）

[English / 简体中文](README.md)

**C++17** と **OpenGL 3.3（Core Profile）** を使用した、コンウェイのライフゲームの対話型シミュレーターです。盤面上でセルを配置し、世代ごとの変化をリアルタイムで観察できます。

## 主な機能

- **セルの描画**では、左ボタンを押した時点でセルが生存状態になります。ドラッグ中は取得したカーソル位置の間にあるセルも埋めるため、素早く動かしても線が途切れません。左ボタンを離すか、カーソルがウィンドウの外に出ると描画が区切られます。
- **視点操作**は、右ボタンを押したままドラッグして表示範囲を移動し、マウスホイールで拡大・縮小します。
- **一時停止中**も、セルの描画や盤面のクリアができます。アプリはウィンドウのイベントを待って再描画し、再開すると停止した世代からシミュレーションが続きます。
- **最小化時**は、GLFW がウィンドウの最小化を報告するか、フレームバッファーのサイズがゼロになると描画を停止します。シミュレーションが実行中の場合は世代更新の間に待機し、ウィンドウを元に戻したときに最新の盤面を表示します。

## 操作方法

| 操作 | 動作 |
| --- | --- |
| 左クリック・左ドラッグ | セルを生存状態にする |
| 右ドラッグ | 表示範囲を移動する |
| マウスホイール | 拡大・縮小する |
| Space | 一時停止・再開を切り替える |
| C | 盤面をクリアし、すべてのセルを死滅状態にする |
| Esc | アプリを終了する |

## ビルドと実行

### 必要な環境

1. **CMake 3.15 以上**
2. **C++17 対応コンパイラー**（Windows は Visual Studio 2019 以降の MSVC、Linux/macOS は GCC 8 以降または Clang 7 以降）
3. **OpenGL 3.3 Core Profile** に対応するハードウェアとドライバー
4. **GLFW 3.4 以降の 3.x 系**

### Windows（Visual Studio）

プロジェクトのルートディレクトリで PowerShell またはコマンドプロンプトを開き、以下のコマンドを実行します。

1. **CMake で構成する**

   ```powershell
   cmake -S . -B build
   ```

   初回の構成時に CMake が GLFW 3.4 のソースをダウンロードし、ハッシュを検証します。初回のダウンロードにはインターネット接続が必要です。GLFW はビルド時にソースからコンパイルされるため、`glfw3.lib` の事前インストールは不要です。

2. **ビルドする**

   ```powershell
   cmake --build build --config Release
   ```

   デバッグ版をビルドする場合は、`cmake --build build --config Debug` を実行します。リリース版は `bin/Release/GameOfLife.exe`、デバッグ版は `bin/Debug/GameOfLife.exe` に出力されます。

3. **実行する**

   ```powershell
   .\bin\Release\GameOfLife.exe
   ```

   シェーダーは実行ファイルに埋め込まれているため、任意の作業ディレクトリから起動できます。

### Linux / macOS（オプション）

OpenGL の開発ファイルと、CMake 用のパッケージ設定を含む GLFW 3.4 以降の 3.x 系の開発パッケージをインストールしてください。パッケージマネージャーで GLFW 3.3 しか入手できない場合は、対応バージョンを別途インストールし、構成時に `-DCMAKE_PREFIX_PATH=<prefix>` でインストール先のプレフィックスを指定してください。

プロジェクトのルートディレクトリで以下を実行します。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
./bin/Release/GameOfLife
```

GLFW 3.4 の Wayland バックエンドではウィンドウの最小化が通知されません。この環境では、フレームバッファーのサイズがゼロになったときに描画を停止します。
